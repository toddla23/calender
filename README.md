# 바탕 달력

라즈베리파이에서 직접 운영하는 바탕화면 달력입니다. 날짜 칸에 메모를 바로 적고, 윈도우 바탕화면 앱과 휴대폰, 브라우저가 실시간으로 동기화됩니다.

## 기능

### 달력과 메모
- 칸을 **더블클릭**하면 바로 편집합니다(휴대폰은 **탭**하면 아래에서 편집 시트가 올라옵니다). 다른 곳을 누르거나 `Esc` 를 누르면 자동 저장됩니다.
- 편집기 아래 동그라미로 칸 배경색을 고릅니다.
- **이력**에서 칸의 이전 버전을 보고 되돌릴 수 있습니다(칸당 최근 100개).
- `PageUp` / `PageDown` 또는 `‹ ›` 로 달을 옮깁니다.
- 한국 공휴일(음력 공휴일·대체공휴일 포함, 2025~2030년)이 표시됩니다. 선거일 같은 임시공휴일은 직접 추가할 수 있고, 모든 기기에 바로 반영됩니다.

### 동기화
- 한 기기에서 고치면 다른 기기에 1초 안에 반영됩니다.
- 오프라인에서도 마지막으로 받은 달력을 보고 고칠 수 있습니다. 고친 내용은 기기에 저장했다가 연결되면 보내고, 그동안 오른쪽 위에 `오프라인 · 대기 N` 으로 표시됩니다.
- 두 기기에서 같은 칸을 동시에 고치면 한쪽을 버리지 않고 `--- 다른 기기에서 수정 ---` 구분선으로 합쳐 충돌 표시를 합니다. 정리해서 저장하거나 "충돌 표시 해제"를 누르면 풀립니다.

### 윈도우 앱
- 테두리 없는 달력 창이 바탕화면에 붙습니다. Win+D 를 눌러도 보이고, 작업표시줄에는 나타나지 않습니다.
- 표시 방식: **바탕화면에 붙이기**(기본) / **항상 다른 창 아래** / **일반 창**
- 위쪽 막대를 끌어 옮기고, 가장자리를 끌어 크기를 바꿉니다. 위치·크기를 잠글 수 있습니다.
- **트레이 아이콘**: 왼쪽 클릭으로 보이기/숨기기, 오른쪽 클릭으로 보이기/숨기기·설정·종료
- **설정 → 윈도우 앱**: 배경색, 글자색, 배경 불투명도(0%까지), 글자 크기, 윈도우 시작 시 자동 실행
  - 배경색 "기본"은 시스템 테마(밝게/어둡게)를 따르고, 글자색 "기본"은 배경 밝기에 맞춰 검정/흰색이 정해집니다.
  - 불투명도 0%면 배경 없이 글자와 격자선만 바탕화면 위에 보입니다.
- 처음 실행할 때 브라우저로 Google 로그인을 한 번 하면 이후에는 다시 묻지 않습니다.

### 휴대폰
- **Android 앱**: 주소창 없이 앱 화면으로 열립니다. 서버를 업데이트하면 앱도 바로 바뀝니다.
- **홈 화면에 추가 (PWA)**: Android Chrome ⋮ → **홈 화면에 추가**, iPhone Safari 공유 → **홈 화면에 추가**. 앱처럼 전체 화면으로 뜹니다.

### 설정과 계정
- 허용한 Google 계정으로만 로그인할 수 있습니다.
- ⚙ 설정에서 로그인된 기기 목록을 보고 폐기할 수 있습니다.
- **JSON 내보내기/가져오기**: 달력을 파일로 받고, 가져오면 파일에 있는 날짜만 덮어씁니다(덮어쓴 칸은 이력에 남음).
