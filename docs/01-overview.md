# 01. 개요

## 무엇을 만드는가

**바탕 달력**(deskcal)은 라즈베리파이에서 직접 운영하는 바탕화면 달력이다.

- 날짜 칸에 메모를 바로 적는다. 칸마다 배경색을 고르고, 이전 버전으로 되돌릴 수 있다.
- 윈도우 바탕화면 앱(Tauri), 휴대폰(Android 앱·PWA), 브라우저가 **실시간으로 동기화**된다.
- 오프라인에서도 보고 고칠 수 있다. 고친 내용은 연결되면 보낸다.
- 서버와 DB는 집 라즈베리파이 한 대에서 돌고, Tailscale Funnel로 인터넷에 공개된다.

## 원칙 (모든 설계 판단의 기준)

1. **개인용.** 달력은 하나이고, 로그인할 수 있는 사람은 `ALLOWED_EMAILS` 허용 목록뿐이다(D-001, D-002). 여러 사람으로 넓힐 가능성만 열어 둔다.
2. **공개 서비스처럼 지킨다.** Funnel로 인터넷 전체에 열려 있으므로 모든 API·WebSocket은 인증이 필요하고, 서버는 `127.0.0.1`에만 연다(D-004). 보안 항목은 02-architecture "보안".
3. **수정이 사라지지 않는다.** 편집은 디스크 큐에 먼저 저장하고 보낸다. 동시에 고친 내용은 덮어쓰지 않고 합친다(D-009). 모든 버전은 이력에 남는다.
4. **가볍게.** 파이에서 돌고 바탕화면에 상주하므로 메모리·CPU·설치 크기에 목표값을 두고 잰다(02-architecture "측정값").
5. **화면 코드는 한 벌.** 웹·PWA·윈도우 앱·Android 앱이 같은 `web/` 코드를 쓴다(D-006, D-008).

## 플랫폼별 동작

| 플랫폼 | 형태 | 편집 | 오프라인 |
|---|---|---|---|
| Windows | Tauri 앱. 바탕화면 아이콘 레이어에 붙음, 트레이 상주 | 칸 더블클릭 | 파일 캐시 + 큐 |
| Android | TWA 앱(Chrome으로 웹앱을 주소창 없이 띄움) 또는 PWA | 칸 탭 → 아래 편집 시트 | IndexedDB 캐시 + 큐 |
| iPhone | PWA (Safari → 홈 화면에 추가) | 칸 탭 → 아래 편집 시트 | IndexedDB 캐시 + 큐 |
| 브라우저 | 웹앱 | 칸 더블클릭 | IndexedDB 캐시 + 큐 |

## 용어

| 용어 | 뜻 |
|---|---|
| 칸 / 노트 | 한 날짜의 메모. 내용·색·`version`·충돌 표시를 가진다 |
| op | 클라이언트가 보내는 수정 하나. `{opId, date, baseVersion, content?, color?}` |
| `seq` | 서버 변경 번호. 모든 변경에 하나씩 늘어난다 |
| `since` | 클라이언트가 마지막으로 받은 `seq`. 이 뒤의 변경만 받아 온다 |
| 충돌 | 같은 칸을 다른 기기가 먼저 고쳐서 `baseVersion`이 맞지 않는 경우 |
| 큐 | 아직 서버가 받았다고 답하지 않은 op 목록. 디스크에 저장된다 |
| Funnel | Tailscale Funnel. 파이의 로컬 포트를 `*.ts.net` HTTPS 주소로 공개한다 |
